착한맛자랑서비스 시작

개인정보처리방침

시행일 2026년 11월 11일 · 적용 대상: 착한맛자랑 웹사이트, iOS·Android 앱

요약 — 착한맛자랑은 회원가입이 없고, 이용자의 개인정보를 서버에 수집·저장·전송하지 않습니다. 위치·저장한 가게·메모·사진은 이용자의 기기 안에서만 처리됩니다.

1. 처리하는 정보와 목적

정보처리 위치목적보관
현재 위치(위도·경도)이용자 기기 안가까운 서비스 지역과 가게 거리 계산저장하지 않음(앱 사용 중 메모리에만)
저장한 가게·코스, 메모, 맞춤 조건, 뽐내기 기록이용자 기기의 브라우저/앱 저장소내 리스트 기능 제공이용자가 삭제할 때까지
뽐내기 사진이용자 기기 안공유 카드 이미지 생성저장·업로드하지 않음

위 정보는 운영자에게 전송되지 않으며, 운영자는 이를 열람할 수 없습니다.

2. 수집하지 않는 정보

  • 이름, 이메일, 전화번호 등 회원 정보(회원가입 없음)
  • 광고 식별자, 행동 추적 정보(광고·분석 SDK 없음)
  • 결제 정보

3. 권한

  • 위치(선택): "내 위치로 찾기"를 누를 때만 요청합니다. 거부해도 지역을 직접 골라 모든 기능을 쓸 수 있습니다.
  • 사진(선택): 뽐내기에서 사진을 고를 때만 사용합니다.

4. 외부 서비스

앱은 최신 가게 데이터를 착한맛자랑 웹사이트(GitHub Pages)에서 내려받습니다. 이때 일반적인 웹 요청과 같이 접속 IP 등이 호스팅 사업자(GitHub)에 기록될 수 있습니다. 가게의 블로그·유튜브·지도 링크를 누르면 해당 서비스로 이동하며, 그 서비스의 개인정보처리방침이 적용됩니다.

5. 가게 정보에 관하여

가게명·주소·업종·좌표와 블로그·영상의 제목·링크·날짜 등 공개된 영업 정보만 공식 API로 수집합니다. 개인 작성자의 본문·사진은 저장하지 않습니다. 사장님께서 가게 정보 수정이나 삭제를 원하시면 아래로 요청해 주세요.

6. 이용자의 권리와 삭제 방법

  • 앱: 기기 설정에서 앱 데이터 삭제 또는 앱 삭제
  • 웹: 브라우저 설정에서 사이트 데이터 삭제
  • 위치 권한: 기기 설정에서 언제든 끌 수 있습니다.

7. 아동

만 14세 미만 아동의 개인정보를 별도로 수집하지 않습니다(회원가입·서버 수집 없음).

8. 문의

개인정보 관련 문의와 가게 정보 수정·삭제 요청: GitHub 문의 게시판 · 고객 지원

9. 변경

방침이 바뀌면 이 페이지에 시행일과 함께 알립니다.
